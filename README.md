## Project Overview

**SIASA HUB** provides a neutral, structured space where political leaders can:

- Publish their **campaign manifestos and policy priorities**
- Share their **track record** (past roles, achievements, public service history)
- Engage **transparently with citizens**

Citizens can:

- Access **verified political information**
- Review and compare **leaders’ manifestos and track records**
- Participate in **group discussions** on key issues like **youth development, governance, education, and innovation**

**Project Goals:**

1. **Transparent manifesto & track record publishing**  
2. **Public engagement & discussions**  
3. **Scalable civic infrastructure for 2027 & beyond**  

> ⚠️ SIASA HUB is **neutral** and not affiliated with any political party or candidate.

## Getting Started

### Prerequisites
- Node.js >= 18  
- npm >= 9  
- Docker (for containerized services)  

### Installation
```bash
# Clone the repo
git clone https://github.com/SIASA-HUB/siasa-hub-platform.git

# Navigate to the project folder
cd 

# Install dependencies
npm install

# Start the development server
npm run dev
